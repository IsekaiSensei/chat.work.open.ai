# TO WORLD — Reference Shelf

This repository is no longer the multi-agent command center, Drive mirror, or agent-ordering system.

## Current working arrangement

- **ChatGPT Library is the local working hub** for the materials we actively use together: project references, notes, discoveries, working documents, and generated artifacts.
- **Google Drive is no longer mirrored into GitHub.** Do not create or maintain duplicate folder structures, synchronization procedures, or agent-specific Drive handoffs.
- **GitHub is optional publication and code hosting**, used only when a particular project or release needs a repository. It is not the place where every AI receives orders, posts read receipts, or coordinates a chain of agents.
- **Agent profile files** are reference cards, not instructions or task queues. They may contain:
  1. the existing personality matrix and character portrayal;
  2. interactive notes that help distinguish the agent's conversational behavior;
  3. useful discoveries about the platform's publicly documented capabilities, defaults, limitations, and observed behavior.
- Agent observations must identify their basis: **PUBLICLY DOCUMENTED**, **DIRECTLY OBSERVED**, **OWNER-DESCRIBED**, or **UNVERIFIED**. Do not turn a single interaction into a universal claim. Do not present private project interpretations as public facts.
- Remove command hierarchies, standing orders, agent dispatch rules, mandatory read receipts, task queues, mirrored handoffs, and role claims that imply one AI controls another.
- Ryan remains the author and final decision-maker for TO WORLD. A profile does not grant an agent access, permissions, authority, or an assignment.

## What belongs here

Keep only material that has a clear reason to live in this repository: code, public releases, intentionally shared reference material, and the concise agent profiles described above. Do not bulk-migrate the private working library here.

## Source and history

Git history retains earlier repository revisions. Historical material is not current instruction. Old task packets, orders, and handoffs must not be treated as active simply because they remain in repository history or archived folders.
