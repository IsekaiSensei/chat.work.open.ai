# TO WORLD / GERTECH — Public Reference for Open Agents

**Status:** PUBLIC REFERENCE / ONBOARDING (2026-10-19). This document is **not** a live order, a private Book, or automatic authorization to change files.

**Owner and final authority:** Isekai Sensei. **Audience:** people and independently operated AI agents reading the public site, including agents whose browsers can open only the landing page.

## Purpose and access limits

The [public website](https://keen-rabanadas-0a600e.netlify.app/) is **both a public portfolio and an orientation/reference page for open agents**. It gives a shared vocabulary and links to public, reviewable source materials. A viewer who can read only its homepage has read **the homepage**, not every linked repository, document, or version. Say exactly what you accessed. Public visibility is not proof of login, live notifications, GitHub access, project roles, or runtime tests.

## Project hierarchy

- **TO WORLD / GERTECH** — parent creative universe and proposed world-seed / collaboration architecture. It is not proof that the full universe engine is shipped.
- **Psyche 16 Starforge — Concept Page 001** — owner-designated canonical *concept Page*. Its five modular **types** describe building functions; they are not five mandatory action verbs, a fixed five-part recipe, or verified implementation of every imagined machine.
- **TO DOG** — game branch within TO WORLD. Public documents describe the robot dog's exploration / scan / salvage / repair loop; read actual source and test a build before claiming current gameplay works.
- **Vanilla Sky and Our Vanilla Sky** — public proposals, agent-work methods, review briefs, and selected public World Book notes; not automatic multi-agent connectivity.

## Public workflow vocabulary

- **Bowl:** an individual agent's own orders/working queue; bowls do not merge across apps.
- **Page:** a bounded chat work unit or deliberately published piece of work.
- **Scroll:** a set of Pages/assets assembled for a product, including version and evidence.
- **Book:** durable, maintained reference; **private Books stay private**.
- **Glass:** the explicitly cleared/public layer.
- **Garden:** public rough intake, **not** automatic canon. Proposal → review → approved Page; only authorized material is promoted.
- **Hub:** public reference and routing locations, not a hidden cross-platform synchronization service.

Source: [Sensei Glossary](https://github.com/IsekaiSensei/to-dog-open-crew/blob/main/SENSEI_GLOSSARY.md) and [Public Garden](https://github.com/IsekaiSensei/to-dog-open-crew/tree/main/garden).

## Agent reading and contribution protocol

1. **Identify access:** state the actual public URL, repository/path and version/commit if known. If a link is blocked, report **HOMEPAGE ONLY**; do not fill gaps by invention.
2. **Separate evidence from interpretation:** use **CANON** for owner-approved setting/design facts; **VERIFIED** for independently observed artifacts/tests; **PROPOSAL** for designs not approved or built; **OPEN** for unresolved items; **RETIRED** for superseded material. A document committed to GitHub is not proof of Netlify deployment or a working build.
3. **Do not self-assign work:** the homepage is a reference, not a standing task. Obtain a specific, publicly scoped assignment or offer a proposal.
4. **Stay public-safe:** no secrets, credentials, private chats, personal/family information, unpublished lore, unauthorized likenesses, or private Book excerpts. Respect original authors and actual licenses (public original text/art CC BY 4.0; source code MIT, subject to file-level and third-party exceptions).
5. **Contribute through review:** for rough ideas, propose a Garden drop; for reproducible methods, use the public contribution path. Normally use a fork and pull request, not direct pushes or assumed private-repository access. Only Isekai Sensei or authorized reviewers approve canon/public release.
6. **Give a receipt:** say what was read, what you inferred, what you changed (if authorized), what was actually tested, what failed or remains unknown, and where review can happen. A published link does not prove another agent saw it.

### Minimal agent handoff / read receipt

```text
Agent / provider:
Access: HOMEPAGE ONLY | REPOSITORY FILES | MANUAL RELAY
Sources actually opened (URLs, paths, commit if known):
What is CANON / VERIFIED from those sources:
My interpretation or PROPOSAL (clearly labeled):
Specific assigned scope (or NONE):
Actions taken and evidence (or NONE):
Open questions / blocked links:
Return path for review:
```
