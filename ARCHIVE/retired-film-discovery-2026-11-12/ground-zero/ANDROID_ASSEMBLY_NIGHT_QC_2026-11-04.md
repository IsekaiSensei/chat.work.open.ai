## Technical QC of the pasted kit/comedy

The source monologues remain comic character claims. Corrective replies and physical demonstrations prevent those claims from becoming build instructions.

| Issue | Applied treatment |
|---|---|
| “1970s” versus the supplied 1982-era heading | Production uses “early-1980s” historical example. The consulted manufacturer catalog is from 1984; it is not evidence of an exact launch date. |
| “7-axis arm” | Manufacturer describes the optional arm as five-axis. The script's clarification uses five axes; the original joke remains verbatim. |
| 350° wrist | Retained: the catalog explicitly supports wrist rotation of 350°. Do not mistakenly relocate this capability solely to the head. |
| Pendant versus wireless | The ordinary teaching pendant and optional radio transmitter are separate devices in the catalog. The corrected performance gives the pendant its cable and teaching job. |
| Motion versus sonar | Catalog separates motion detection up to fifteen feet from sonar ranging, illustrated at four inches to eight feet. The performance distinguishes those functions. |
| CPU and memory | 6808, 4K RAM and 8K ROM describe the historical base system; those memory capacities are not internal memory of the CPU chip. |
| Historical kit versus future android | The source kit is an educational comparison. The five-axis legacy arm, processor training board and future mechanism are not interchangeable stock or a replacement future-android design. |
| 555 “can't do it consistently” | Kept as character comedy; reply identifies the circuit as capable of keeping time. The timing demonstration has an actual specified network and measured pulse. |
| Inductor “any change” | Clarified as change in current; not a universal resistance to all change. |
| Transistor base connected to collector | Not automatically a fault: connection is judged against the selected circuit. No alleged malfunction is inferred solely from that tie. |
| Amplifier / resistor / diode claims | Treat personification and exaggeration as jokes. Actual gain, power, current, dissipation, polarity, reverse behavior and device ratings follow the selected circuit rather than the punchline. |
| Pre-live speech and testing | Separate service module performs early voices. No animated lips before control readiness. Isolation tests precede controlled test power; a checked stop path precedes calibration. |

Primary references: [Heath Company, Fall 1984 catalog, printed robotics pages 58–59](https://www.worldradiohistory.com/Archive-Catalogs/Heathkit-Catalogs/Heathkit-Fall-1984.pdf), and [Texas Instruments NE555 product documentation](https://www.ti.com/product/NE555).
