# Public contractor briefs — Our Vanilla Sky

Status: PUBLIC WORKFLOW / PROPOSAL. Owner: Ryan Aaron Luzader Jr. (IsekaiSensei).

## Purpose
This public repository is an outward-facing review and contribution surface. Public agents are **independent, task-scoped contractors**, not members of the private project command chain. They receive only the minimum art direction, code direction, interfaces, and acceptance criteria needed for a specific assignment—not the full project history, private discussions, internal rosters, unreleased media, or confidential assets.

## What may be shared for review
- Publicly released scripts and original artwork, with links to the published originals and rights verified.
- Small art-direction briefs: one asset/shot, style tags, dimensions, reference rights, deliverable, and a simple PASS/FAIL rubric.
- Small code-direction briefs: isolated function or prototype, supported engine/runtime, inputs/outputs, reproducible test, and licensing.
- Agent coordination patterns, role boundaries, public handoff formats, failure lessons, and documented experiments that could benefit human–AI collaboration.
- Anonymized, permission-cleared examples; no secrets, personal records, credentials, private URLs, or undisclosed work.

## Contractor packet (copy for each assignment)
**ID:** PUBLIC-YYYYMMDD-NNN  
**Track:** ART / CODE / REVIEW / RESEARCH  
**Question or task:** one narrowly bounded request  
**Public context:** only what is essential  
**Direction:** art or code specifications  
**Inputs:** public links and rights-cleared files  
**Deliverable:** exact file or review format  
**Acceptance:** observable tests and criteria  
**Rights:** source author, asset titles, license, third-party restrictions  
**Status:** PROPOSAL / VERIFIED / FAIL / OPEN  
**Return path:** issue or pull request; no assumed receipt

## Boundaries
- Public contractor work is untrusted until reviewed; no automatic merge, publication, canon, or production promotion.
- Contractors may not delegate, scrape private project data, or claim to represent OpenAI or the TO DOG command team.
- Work remains attributed to its actual authors. Credit each original artwork and script by title and creator where available; include source, license, and changes. CC BY 4.0 is a proposed default for eligible original creative works, not an automatic relicense of existing or third-party material. Software needs its own explicit license.
- A public GitHub submission is not a submission to OpenAI, a guarantee of model training, or a promise of review.
- Preserve rejected work and its evidence in an appropriate archive; do not silently erase failures.

## Intake flow
Ryan or the authorized core crew selects a cleared, minimal task → publish the brief → independent contractor returns a draft → review against criteria → record decision and attribution → promote only with explicit authorization.

**Operating rule:** CHECK GITHUB FIRST — LIVE ORDERS FIRST AND LAST for internal promotion decisions. Public contractors receive only the published packet, not private orders.
