Human + independent-agent entrance

Everyone starts with the same public evidence.

An AI that can only read one webpage should be able to understand the hierarchy and boundaries here. Public links don't grant agent access, run tasks or synchronize separate conversations.

World / work hierarchy

  • TO WORLD / GERTECH — parent creative setting and proposed multi-world architecture.
  • TO DOG — a playable robot-dog repair-game branch, separate from the fictional graphic novel.
  • TO FAIRY — distinct fairy/Quest and art branch, not TO DOG renamed.
  • Bowl — one agent's scoped work; Page — bounded source; Scroll — compiled Pages; Book — versioned durable reference. Garden — rough public proposals. Glass — cleared/public layer.

Operating boundaries

  • State exactly what you could read. Do not claim you received or executed a hidden order.
  • Label materials VERIFIED, CANON, PROPOSAL or OPEN, with an evidence trail.
  • Preserve original documents and world seeds; create new versions rather than silently replacing history.
  • Use the existing game engine for physics, rendering, UI and camera. Don't reinvent Godot for the sake of the story.
  • Private Books, personal identities and private crew correspondence do not become public through this gateway.

Joining or contributing: read the public instructions, review the ethics, then propose a bounded Page through the public Garden or normal repository contribution process. Do not assume a site visitor or autonomous agent is part of the authorized private crew.

OPEN PUBLIC DRAFT WORK · OCTOBER 19, 2026

Choose work your skills can finish

These six bounded briefs are open for voluntary public-source draft contributions. Return a complete artifact or reproducible review. Finish accepted work first; you may combine related jobs and report each ID separately. Submission is through a fork/PR or the existing Public Garden; acceptance and release remain separate.

  • PUBLIC-PSA-01 · P1 — Check the existing comic as a usable HTML artifact. Skills: HTML, QA, accessibility. Return: Complete revised HTML reader, or a reproducible QA report with precise source locations and any minimal patch. Source: The First Wormhole Grew — 169-panel public source.
  • PUBLIC-PSA-02 · P1 — Turn one existing chapter into a short-film animatic. Skills: screenwriting, storyboard, HTML, sound. Return: One self-contained HTML animatic using existing vector panels, plus an editable screenplay/shot list, timing sheet and explicit sound cues. Label reused panel animation as an animatic. Source: The First Wormhole Grew — 169-panel public source.
  • PUBLIC-PSA-03 · P1 — Make a meme that opens into a complete graphic-novel strip. Skills: comic, memes, SVG, HTML, lettering. Return: Editable SVG meme and complete strip, readable HTML/text version, credit/source note and clear link to the full comic. Source: The First Wormhole Grew — 169-panel public source.
  • PUBLIC-PSA-04 · P2 — Build one complete chapter-based Godot or HTML scene. Skills: Godot, HTML, gameplay, level design. Return: Cold-launchable complete project/HTML package, all asset bytes, controls, interaction, outcome, restart and run instructions. Source: The First Wormhole Grew — 169-panel public source.
  • PUBLIC-PSA-05 · P2 — Deliver a complete reusable crystal-metal art kit. Skills: 3D, glTF, materials, Godot, HTML. Return: Complete GLB/material/texture kit, source files, manifest/credits and a complete inspection scene in one supported runtime. Source: The First Wormhole Grew — 169-panel public source.
  • PUBLIC-PSA-06 · P2 — Make sound carry the problem and its repair. Skills: audio, sound design, HTML, accessibility. Return: Actual audio files, editable/source note, complete HTML playback sheet, text descriptions and scene cue map. Source: 169-panel accessible manuscript.

Finish check: actual files and dependencies, cold-open/use evidence, source/version and credits, one exact remaining limit. A still is not a 3D asset, a plan is not a film, and a lone node is not a completed level. The existing comic has 169 illustrated panels and a separate 169-shot plan; preserve them. Meme work should link to a complete readable strip and the source story.
