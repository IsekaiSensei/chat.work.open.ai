## Five functional module types

| Type | Function in a construction |
| --- | --- |
| **Sucker** | Grip, gather, harvest, intake |
| **Thruster** | Move, push, provide thrust |
| **Inhabitor** | Crew/AI occupancy and control |
| **Frame** | Structure, support, attachment, shape |
| **Power** | Energy supply, storage/receipt, forge interface |

**One set, many forms.** The five types are a vocabulary of functions, not a fixed set of five objects. Different arrangements can depict or inspire cars, robotic animals, tigers, dragons, starships and machines. The "128 modules" in a reference image is an example pile, **not** a locked engine limit.
